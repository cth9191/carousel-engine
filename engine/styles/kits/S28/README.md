# S28 Alpine Product Window: card kit

Starter pages for S28 (spec: `engine/styles/S28-alpine-product-window.prompt.md`). Codex paints three
text-free plates per deck (scene, cover, CTA); these pages render every word, chip, window and icon over
them. The kit mirrors a deck folder, so the relative paths (`../fitted/`, `../shots/`, `../logos/`) work
unchanged once copied. The corner label and the counter print `{{BRAND}}`: replace it with the `brand` in
`engine/brand.json` when you copy the pages.

| Path | What it is |
|---|---|
| `cards/s28.css` | Tokens and components: plate backgrounds, interior veils, item head (tile, name, what, chips with the five warm tints in order), combo pair, before/after stake, window (bar + source label, capture / mono text / split cells), three-cell footer, counter, corner micro-labels, cover hook stack, CTA stack |
| `cards/icons.js` | The Lucide glyphs the pages use (generated by `shared/lucide-icons.mjs`) |
| `cards/page-01.html` | **Cover** over `../fitted/cover.png` (slots already filled): micro-labels, giant numeral, caps noun, Caveat Brush word over a drawn underline, closing line |
| `cards/page-02.html` | **Before / after**: the stake with one orange word, subtitle, split window (✕ without / ✓ with), footer |
| `cards/page-03.html` | **Item** with a real mark on a white tile |
| `cards/page-04.html` | **Item** with no mark: a cream Lucide glyph on #111111 with the orange spark |
| `cards/page-08.html` | **Combo**: two 130 px tiles + "+", the pair's job, 3 chips, one capture of both at work |
| `cards/page-09.html` | **CTA** over `../fitted/cta.png`: message glyph, COMMENT, keyword on a cream block, deliverable |
| `cards/tile-01.html` … `tile-05.html` | One cover-slot tile each, rendered to `logos/tile-NN.png` (256 css px @2x, 22% corner radius, transparent corners) for `composite.py --logo` |
| `shared/lucide-icons.mjs` | Writes `cards/icons.js` from `shared/vendor/lucide/` |
| `placeholder/plate-*.html` → `fitted/*.png` | Flat gradient stand-ins for the three plates. **Placeholders only, labelled as such; never ship them** |
| `shots/` | Placeholder captures: replace with each item's real README / UI / terminal capture |
| `logos/` | Sample marks (Claude, Anthropic, OpenAI as SVG + PNG), GitHub's simple-icons mark (`github.svg`, `github-ink.png`), the sample tiles. Your own marks come from your logo folder or simple-icons |
| `samples/` | Every page rendered over the placeholder plates (exit 0 each), with `{{BRAND}}` filled as `YOUR BRAND` |

## Use it for a deck

```bash
D=carousels/YYYY-MM-DD-slug
mkdir -p $D/cards $D/logos $D/shots $D/plates $D/fitted $D/exports
cp engine/styles/kits/S28/cards/* $D/cards/
# 1. plates: shared/codex-img.mjs, SYSTEM + the layout's Plate paragraph (+ KEYING for the cover), 2 variants each
python -I shared/composite.py $D/plates/scene.png $D/fitted/scene.png      # exit 3 = stray magenta: edit job
python -I shared/composite.py $D/plates/cta.png $D/fitted/cta.png
# 2. cover tiles: one tile-NN.html per item (real mark on #FFFFFF / #111111, or a cream Lucide glyph on #111111)
node shared/render-card.mjs $D/cards/tile-01.html $D/logos/tile-01.png --w 256 --h 256 --scale 2 --min-px 0
python -I shared/composite.py $D/plates/cover.png --zones-only                # exactly N cyan zones, fill ≈ 0.95
python -I shared/composite.py $D/plates/cover.png $D/fitted/cover.png --logo 1=$D/logos/tile-01.png@1.0 --logo 2=...
# 3. pages: copy the layout page to page-NN.html per slide, replace every string, then
node shared/lucide-icons.mjs $D/cards/icons.js --from $D/cards
node shared/render-card.mjs $D/cards/page-NN.html $D/exports/slide-NN-YYYY-MM-DD.png --w 1080 --h 1350 --scale 1 --min-px 20
```

Deck order: cover, optional before/after, items (6 at most), optional combo, CTA; 10 slides at most.

## Fit and limits (measured on the kit)

- Item head (y 34-492) is one `[data-fit]` column: name one line 104 → 76 px, wrapping to a second
  line only at 76; what ≤ 14 words (2 lines at 34/40); chips 3-5, and the fit pass drops chips from the
  end (never below 3) until the row fits 952 px.
- Footer cells hold 2 lines of 26 px, about 15 characters a line ("Replaces guessing token spend" is
  3 lines and fails; "Replaces token guesswork" fits). The proof cell's star glyph is the icon, so the
  text reads "141.5k stars · MIT".
- Before/after stake: ≤ 7 words, 96 → 76 px, 2 lines. The split cells are about 430 x 575 px each:
  capture the same task at that portrait-ish aspect, or the contain-fit letterboxes heavily (as the
  placeholder captures do).
- Cover noun: fitted to 520 px between 80 and 64 px, so about 12 caps characters ("GITHUB REPOS");
  "CLAUDE CODE REPOS" fails. Put the subject in the top-right micro-label instead.
- CTA keyword: Anton 190 → 120 px on its cream block, at most 600 px wide (about 7 letters at full size).
- Window sources are mono 20 px #8B9096, the page's smallest text, exactly at the 20 px floor.
- Veils: `--veil-top` .6 and `--veil-foot` .5 in `s28.css`; raise either to .75 if a word on the real
  scene plate reads under 4.5:1.
